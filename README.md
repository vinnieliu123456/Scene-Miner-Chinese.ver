# Scene‑Miner 智驾长尾危险场景挖掘平台
> 自动驾驶数据闭环工具原型

## 📖 项目概述
Scene‑Miner 是一款面向自动驾驶数据闭环上游的AI产品。
自动驾驶测试车每日产出海量摄像头、激光雷达录像，绝大多数都是普通平稳行驶的无效片段；而可以优化感知模型的**长尾危险路况（鬼探头、路面杂物、逆光、大型车辆遮挡行人等）**十分稀少。

传统方案依靠急刹、人工接管等传感器信号触发采集，很多具备潜在隐患的场景无法被捕获。本工具依托VLA多模态视觉大模型 + 向量检索引擎，自动搜寻风险样本，供给后续标注、模型训练，补齐算法短板。
本仓库存放完整产品方案、原型资源。

## 👥 用户画像
1. **数据工程师**：筛取路测录像、整理训练数据集，困扰于人工翻看海量视频；
2. **感知算法工程师**：需要稀缺困难场景，用来迭代优化视觉感知模型；
3. **道路测试工程师**：复盘危险行驶片段，分析自动驾驶潜在隐患。

## ⚙️ 核心AI功能 & 差异化优势
相较于市面上传统触发式筛选工具：
1. **自然语言语义检索**：文字描述危险路况即可搜索对应视频片段；
2. AI双维度打分：自动计算**风险等级**、**样本稀缺分值**，衡量样本训练价值；
3. 识别隐形风险：捕获没有触发急刹、司机接管，但感知置信度异常的隐患片段；
4. 相似场景一键召回，批量收集同类长尾案例；
5. 多路传感器画面预览，AI自动解析风险成因；
6. 合格样本一键推送至标注平台，打通完整数据闭环。

### 🧮 算力成本优化（产品落地设计）
为了规避大模型扫描视频消耗大量 Token 的问题，产品在业务流程层面设置四层节流策略：
1. 结构化数据前置粗筛，平稳无风险录像直接过滤，不调用视觉大模型；
2. 自适应抽帧，静态路况隔多秒取一帧，动态危险场景加密采样；
3. 使用向量数据库预生成特征向量，检索阶段不需要启动重型VLM；
4. 按需推理：列表浏览不会触发深度AI解析，仅用户点开预览弹窗时执行完整分析。

> 底层向量库、模型推理加速交由算法和后端工程师实现。

## 🖥️ 产品原型页面结构
原型为PC端后台管理系统，一共5个核心页面以及弹窗组件：
1. **数据看板**：统计扫描视频总量、高危场景数量、风险类型可视化图表；
2. **AI智能检索页**：自然语言搜索框、天气‑道路类型筛选、风险分滑块筛选；
3. **长尾样本列表**：分页表格、批量勾选、预览、推送标注平台等操作；
4. **视频预览弹窗**：多路摄像头+雷达画面、AI风险解析标签；
5. **批量推送侧边抽屉**：配置数据集名称，批量下发标注任务。

## 🔁 完整业务工作流
车载传感器录制道路视频
→ 前置筛选过滤普通无效片段
→ 多模态AI识别、打分长尾危险场景
→ 工程师检索、预览、筛选样本
→ 批量推送样本到标注平台
→ 标注数据集用于感知模型训练
→ 更新后的模型部署上路，开启新一轮采集，形成闭环
